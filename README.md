# Vira Shop

Стартовый прототип собственного интернет-магазина в стиле современного маркетплейса. **Версия 0.1 — демонстрационная.** В репозитории пока нет реальных заказов, платежей, пользователей или базы данных.

## Запуск на Windows

1. Установить [Node.js LTS](https://nodejs.org/).
2. Скачать репозиторий ZIP и распаковать в папку или выполнить `git clone https://github.com/Freep-o-0-rn/Vira-Shop.git`.
3. Запустить `START-WINDOWS.bat` (или выполнить `npm install`, затем `npm run dev`).
4. Открыть `http://localhost:3000`.

## Реализовано

Адаптивная главная страница; категории; демо-каталог из 12 товаров; поиск и сортировка; карточка товара; избранное и корзина с хранением в браузере. Демо-цены, скидки, рейтинги и остатки вымышлены. Фото загружаются с Unsplash и требуют подключения к интернету.

## Следующие этапы

1. Утверждение дизайна и удобства каталога.
2. PostgreSQL, серверные API, управление ассортиментом, сохранение настоящих цен и остатков.
3. Регистрация, авторизация, заказы, контроль доступа и транзакции.
4. Админ-панель управления товарами и заказами.
5. Платёжный провайдер и доставка после определения страны работы.
6. VPS, Docker, домен, HTTPS, бэкапы, автоматическое развёртывание и мониторинг.

**Важно:** использовать `localStorage` для оформления реальных заказов и доверять цене из браузера нельзя. Платежи отключены специально. Демонстрационные изображения необходимо заменить собственными или лицензированными перед публичным запуском.

## Проверка

После установки зависимостей: `npm run typecheck` и `npm run build`. Автопроверка запускается через GitHub Actions; это не заменяет тестирование интерфейса в браузере.
