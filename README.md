# Vira Shop — интернет-магазин

**Версия 0.3.** Каталог на Next.js и PostgreSQL с приватной административной панелью. Проект пока не принимает реальные заказы и платежи.

## Запуск на Windows

1. Установите [Node.js LTS](https://nodejs.org/) 22+.
2. Скачайте свежий ZIP через **Code → Download ZIP**, распакуйте в новую папку.
3. Запустите `START-WINDOWS.bat`. Сайт работает на `http://localhost:3000` и **без PostgreSQL**, тогда отображаются демонстрационные товары.

## Настройка базы и администратора

Установите и запустите [Docker Desktop](https://www.docker.com/products/docker-desktop/) (WSL 2).

1. Остановите сайт (`Ctrl+C`). Запустите `SETUP-DATABASE-WINDOWS.bat`. Он поднимет локальную базу, создаст `.env.local`, применит SQL-миграции и наполнит каталог 12 учебными товарами. Повторный запуск не перезапишет их.
2. Запустите **`CREATE-ADMIN-WINDOWS.bat`**. Введите логин и придумайте пароль от 12 символов. Ввод пароля скрыт.
3. Запустите `START-WINDOWS.bat` и откройте **http://localhost:3000/admin/login**.
4. Проверьте добавление товара, редактирование цены, остатка, категории, фото и скрытие товара. Обновите магазин — изменения загрузятся из PostgreSQL.

Если у вас своя PostgreSQL, достаточно настроить `DATABASE_URL` в `.env.local` и вызвать:

```powershell
npm install
npm run db:setup
npm run db:seed
npm run admin:create
npm run dev
```

Повторное создание администратора с тем же логином меняет его пароль и завершает старые сеансы входа.

## Возможности

- Каталог: категории, поиск, сортировка, избранное, корзина, цены и остатки.
- Панель `/admin`: CRUD товаров (скрытие вместо физического удаления), создание и редактирование категорий, контроль наличия.
- Доступ только по паролю, хранящемуся в виде scrypt-хеша в PostgreSQL.
- HttpOnly cookie сессии на 24 часа; запрет запросов изменения данных с посторонних Origin.
- Ограничение неверных попыток входа; HTTPS обязателен для публикации.
- Загрузка изображений PNG, JPEG, WebP до 5 МБ **только в локальной разработке** (`public/uploads/`); в production загрузка отключена до внедрения S3-совместимого хранилища.
- Серверное API с параметризованными SQL-запросами.

## API

Открытые маршруты:
- `GET /api/products` — `q`, `category`, `sort`, `page`, `limit`.
- `GET /api/categories` — активные категории.

Только для вошедшего администратора:
- `GET/POST/DELETE /api/admin/session` — статус сессии, вход, выход.
- `GET/POST /api/admin/products` — полный список товаров, создание.
- `PUT/DELETE /api/admin/products/:id` — редактирование, скрытие.
- `GET/POST /api/admin/categories` — полный список категорий, создание.
- `PUT/DELETE /api/admin/categories/:id` — редактирование, физическое удаление пустой категории.
- `POST /api/admin/upload` — загрузка изображения только локально.

## Команды

- `npm run db:setup` — миграции.
- `npm run db:seed` — миграции + 12 тестовых товаров, без перезаписи изменений.
- `npm run admin:create` — создать администратора или сменить его пароль.
- `npm run typecheck`, `npm run build` — проверка TypeScript и сборки.
- `docker compose stop db` — остановить базу без удаления данных.

Не запускайте `docker compose down -v`, если нужно сохранить данные: `-v` удаляет том.

## Важные ограничения

Это учебный MVP, **не публичный магазин**: реальных заказов, оплаты, доставки и регистрации покупателей пока нет. Фото на локальном диске не переживут некоторых сценариев развёртывания контейнера. Для публичной версии потребуется аудит безопасности, HTTPS, секреты и резервные копии, S3-хранилище, серверная пагинация и система заказов с проверкой цены и остатков на сервере. Укажите `APP_ORIGIN=https://ваш-домен` перед развёртыванием: оно проверяется при изменениях в админке.

`DATABASE_URL` не задан — публичный сайт запускается на демотоварах. `DATABASE_URL` задан, но база недоступна — API возвращает 503, пользователь увидит предупреждение и временный демокаталог. В админке база обязательна. Админка отображает максимум 1000 записей, витрина — первые 100 (ограничение этапа 3).

Разработческий пароль PostgreSQL из `compose.yaml` нельзя использовать в интернете. Демонстрационные цены, рейтинги, изображения и остатки вымышлены.

Журналы диагностики: `vira-startup.log`, `vira-database-setup.log`.
