# Vira Shop

Стартовый прототип интернет-магазина. **Версия 0.1 — демонстрационная**: пока нет настоящих заказов, платежей, пользователей и базы данных.

## Запуск на Windows

1. Установите [Node.js LTS](https://nodejs.org/). Нужен Node.js **22 или новее**.
2. На странице репозитория выберите **Code → Download ZIP** и распакуйте архив в обычную папку, например `E:\Work\Vira-Shop`.
3. Дважды щёлкните `START-WINDOWS.bat`. При первом запуске скрипт установит зависимости через npm, затем запустит Next.js.
4. Откройте адрес, который появится в окне, обычно **http://localhost:3000**. Не закрывайте окно, пока используете сайт.

**Если BAT-файл закрылся или сайт недоступен:** откройте файл `vira-startup.log` в папке проекта. Окно новой версии BAT-файла остаётся открытым и показывает ошибку. При необходимости проверьте вручную в CMD:

```bat
cd /d E:\Work\Vira-Shop
npm install
npm run dev
```

Замените путь на свой. Если порт 3000 занят, Next.js может использовать 3001 — ориентируйтесь на строку `Local:` в консоли. Если запуск заблокирован Windows, откройте свойства BAT-файла и проверьте, не требуется ли «Разблокировать».

## Реализовано

Адаптивная главная страница, категории, демо-каталог из 12 товаров, поиск и сортировка, карточки товара, избранное и корзина с хранением в браузере. Демо-цены, скидки и рейтинги вымышлены. Фото загружаются с Unsplash, поэтому для их отображения нужно подключение к интернету.

## Дорожная карта

1. Утвердить дизайн и удобство каталога.
2. PostgreSQL и серверные API для товаров, цен и остатков.
3. Регистрация, авторизация и заказы с проверкой на сервере.
4. Панель управления товарами и заказами.
5. Подключение оплаты и доставки.
6. VPS, Docker, домен, HTTPS, резервное копирование и мониторинг.

**Важно:** цены из браузера нельзя использовать для оформления реальных заказов. Оплата отключена. Изображения необходимо заменить собственными или лицензированными перед продажами.

## Проверка

`npm run typecheck` — TypeScript, `npm run build` — производственная сборка. GitHub Actions выполняет их при каждом коммите и отдельно проверяет скрипт запуска на Windows.
