# Vira Shop

**0.4 — масштабируемый каталог с серверной пагинацией, фильтрами, галереями и страницами товаров.**

В репозитории — прототип интернет-магазина на Next.js, TypeScript и PostgreSQL. Реальные заказы, платежи и доставка пока не доступны.

## Установка (Windows)

1. Скачайте `Code → Download ZIP` и распакуйте проект в новую папку.
2. Для демонстрационного режима достаточно [Node.js LTS](https://nodejs.org/) (22+) и `START-WINDOWS.bat`. Сайт обычно откроется по `http://localhost:3000`.
3. Для товаров из базы установите и запустите Docker Desktop, затем **`SETUP-DATABASE-WINDOWS.bat`**.
4. Если администратора ещё нет, запустите **`CREATE-ADMIN-WINDOWS.bat`**, задайте логин и пароль не короче 12 символов.
5. Запустите `START-WINDOWS.bat` заново. Вход: `http://localhost:3000/admin/login`.

**При переходе с версии 0.3** нельзя удалять том PostgreSQL. `SETUP-DATABASE-WINDOWS.bat` применит новую миграцию **003_product_details.sql**, сохранив существующие товары, категории и администратора. Скрипт не должен перезаписывать созданные вручную карточки.

Если Docker не нужен, настройте собственный `DATABASE_URL` в `.env.local` и запустите:

```powershell
npm install
npm run db:setup
npm run dev
```

`npm run db:seed` — добавляет демоданные только в отсутствующие записи.
`npm run admin:create` — создание или сброс пароля администратора.

## Новое в версии 0.4

### Каталог
- **Серверная пагинация по 12 товаров** на странице с кнопками «Назад» / «Вперёд» и количеством найденных записей.
- Фильтрация по категории, названию, диапазону цены и наличию.
- Сортировка по популярности, цене и рейтингу.
- Счётчик товаров корректен даже при запросе страницы за пределами каталога.
- Корзина и избранное запрашивают товары по ID, включая товары, отсутствующие на открытой странице.
- Без настроенного `DATABASE_URL` сохраняется демонстрационный режим.

### Страницы товаров
- Каждая карточка открывается по `/product/<id>`.
- Название, описание, цена, наличие, характеристики и галерея до восьми изображений.
- Добавление в корзину и избранное из карточки товара.
- Похожие товары из той же категории.
- Скрытые товары и товары скрытых категорий недоступны через публичный API и страницу товара.

### Администрирование
- Дополнительные фотографии можно вводить по одной HTTPS-ссылке на строку.
- Характеристики задаются строками в формате `Название: Значение`.
- Фотографии PNG/JPEG/WebP можно по одной загружать через локальную панель, до 5 МБ; в production локальная загрузка отключена до внедрения объектного хранилища.
- Данные сохраняются в новых колонках `shop_products.images` (TEXT[]) и `shop_products.specs` (JSONB). Старое основное фото автоматически переносится в массив при миграции.

## API

Открытые:
- `GET /api/products?q=&category=&sort=cheap&page=2&limit=12&minPrice=100&maxPrice=5000&inStock=true` — товары, `total`, `totalPages`, `source`.
- `GET /api/products/lookup?ids=p1,p2` — товары по ID (не более 100), для корзины и избранного.
- `GET /api/products/p1` — подробная карточка.
- `GET /api/categories` — доступные категории.

Защищённые административные маршруты: `/api/admin/session`, `/api/admin/products`, `/api/admin/products/:id`, `/api/admin/categories`, `/api/admin/categories/:id`, `/api/admin/upload`. Изменения требуют авторизации и проверенного Origin.

## Ограничения

- Отзывы и рейтинг пока демонстрационные. Приём заказов, оплата и регистрация покупателей отсутствуют.
- Каталог использует **offset pagination** — подходит для MVP и умеренного количества товаров. При большом объёме данных и высоких нагрузках стоит рассмотреть курсорную пагинацию и специализированный поиск.
- Администраторская таблица пока показывает максимум 1000 товаров — это отдельная задача на следующий этап.
- Фото в `public/uploads` сохраняются только локально, а не в постоянном облачном хранилище. Для production необходимы HTTPS, S3-совместимое хранилище, резервные копии, ограничения доступа и аудит безопасности.
- Сервер остаётся одновалютным (RUB). Платёжные суммы в базе сохраняются целыми копейками.
- Перед публичной публикацией задайте `APP_ORIGIN=https://ваш-домен`, замените разработческие пароли из `compose.yaml` и проверьте модель размещения.
- Не запускайте `docker compose down -v`, если хотите сохранить базу.
- Изображения Unsplash и тестовые описания используются только для демонстрации.

## Диагностика

`vira-startup.log` — запуск на Windows, `vira-database-setup.log` — настройка базы. Для ручных проверок `npm run typecheck`, `npm run build`. GitHub Actions проверяет сборку без базы, миграции и интеграционные тесты PostgreSQL.
